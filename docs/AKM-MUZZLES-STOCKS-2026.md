## UI 與驗收
- 13 款槍口、7 款槍托目前列入研究候選（含原先已有）。
- 右側抽屜候選超過 8 件時顯示名稱搜尋欄；槍托只有 7 件，若希望兩類一致保留搜尋，則 UI 以研究候選數目 >=7 啟用。
- 重量、品質、收納格數、快拆標示皆對應個別來源；不同槍械共用部件的「可裝 AKM」仍未驗證，必須顯示警告。
- 以 DOM 原生事件同步右側選擇／左側性能；不新增虛構 2D 配件幾何，也不變更 3D。
- Node 結構與治理測試保護 ID 唯一、算術、strict mode；Chromium 驗證 1440px／390px 選用、搜尋，另回歸 360px／reduced motion／no WebGL／3D。
