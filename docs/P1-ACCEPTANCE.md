## 已完成（有實際 CI 或真實 Chromium 證據）

| 項目 | 驗收 |
|---|---|
| CC0 AKM Blender 原始資料 → 合法 GLB | GH Actions [轉檔成功](https://github.com/waydefu/delta/actions/runs/40024755786)，來源與 SHA256 可追溯 |
| 手機網頁資源控制 | glTF Transform WebP 44,293,464 → 1,092,960 bytes，PBR base/metalrough/normal 均有貼圖、幾何長寬比保持 |
| PBR 原生 Three.js 顯示 | WebGL2、旋轉、縮放、重設視角、材質與網格切換，按需載入和釋放 |
| AKM 彈匣網格分件 | 源模型一個物件但有 28 個不連通幾何島，已分為 AKM_Body（2732 頂點、5172 面）和 AKM_Magazine（80 頂點、150 面），UV 保留 |
| 3D 彈匣裝卸演示 | 獨立節點、短暫按需運動、結束復位，保留減少動態效果偏好，並不改變遊戲配件 |
| 自動化真實瀏覽器 | [Chromium 驗證](https://github.com/waydefu/delta/actions/runs/40027320914)：1440×900、390×844、分件隱藏與動畫檢視全部 PASS，影像 artifact 已保存 |
| 詳細屬性 | 主要數值可跟隨研究配裝更新，開鏡時間與散布等仍保留實測裸槍值，避免虛構公式 |
| 後座力示意誠實標記 | 現在只有有來源逐發實測點才能繪製，無資料時顯示空白框，不畫假彈孔 |
| 資產治理 | GLB 授權／Hash／二進位檔頭、材質與節點有驗證；官方遊戲素材未使用 |

原生 3D 模型由 LonesomeDucky 提供的 CC0 開源模型轉換。不得誤稱為《三角洲行動》原生槍模；兩網格與 demo 不等同遊戲配件系統。若配件數值、相容性缺證據，一律沿用 P0 的 research／verified 雙模式與明示警告。
