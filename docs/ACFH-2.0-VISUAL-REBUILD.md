# ACFH 2.0｜電影級軍械室：視覺重建第一階段

## 目標與定位

使用者希望 DELTA LAB 達到 Active Theory 類型的頂級互動網站**視覺完成度與品質**，而不是複製它的風格、圖像或程式碼。

第一階段重建視覺敘事及主工作台：把 AKM 從一個排列在資料卡中的小圖片，提升成全幅主視覺，與背景、環境光束、空間遠近層、字級、操作指引及 HUD 形成整體。

**這不是高精度分件槍模或即時 3D 寫實光追的完成宣告**。現有 2D 是原生 SVG + 本地 WebP 靜態插畫，3D 是本機已有 GLB、並且仍有較少網格與材質。配件選擇不會修改靜態展示圖的幾何，既有 3D 也不是完整可換件槍械。

## 實際修改

- `index.html`：新全幅 hero 使用本地 2D AKM 圖、工業軍械環境、遠景、聚光與地面視覺層；清楚的雙入口導覽（改槍／詳細性能），底部 status strip，標明研究狀態及 3D on-demand。
- `assets/main.css`：統一字級和空間尺度，深綠／冷灰／霧面金屬語彙；成為完整的一體化軍械舞台，不是不同時期的卡片堆疊。右側槍械舞台加強背景深度、柔光、材質感，左側即時性能資訊維持唯一來源。
- `src/armory-director.mjs`：在可用指標裝置上，滑鼠移動時才以 requestAnimationFrame 更新 CSS 轉換；使用 IntersectionObserver 限制離屏工作。指標離開、動效關閉、系統 reduced-motion、觸控／窄裝置則靜止。**沒有首屏新增 3D、WebGL 或額外外部 CDN**。
- 原本 `src/app.mjs`、`src/engine.mjs`、研究用精調 `src/precision.mjs`、資料庫及懶載入 3D 互動未更動。

## 重要設計原則

- 真正的主視覺是使用者原本批准重繪的 AKM 本地 WebP；圖片載入失敗就顯示現有 SVG 作降級。不盜用 Active Theory 或遊戲官方畫面。
- 沒有把背景的假光暈宣稱為真實 PBR 陰影，沒有造出可換件的網格。
- 重要內容仍是可選取的 HTML 文本；hero 場景元素 `aria-hidden`，兩個 CTA 是原生錨點，無 JS 也能點擊。
- 平板與手機使用可適應尺寸、低亮度光影、無 WebGL 視差；不強制 3D 首載。
- 光影透過静態 CSS layers，僅交互時修改 transform，避免常駐持續渲染、粒子與重型後處理。
- 保留原有 11 個槽位、精調對照、裝配抽屜、原生 GLB 檢視及 source warnings。

## 必須通過的驗收

- Node：場景具分層本地資產、雙 CTA、動效啟停、視差位置限幅、無 eager 3D、原有資料及改槍計算。
- Chromium：桌面 1440 寬、390／360px 手機，hero 載入成功、可觸控 CTA、無橫向溢出、桌面視差可動、手機與 reduced-motion 無視差，原本 2D 工作台可選配件並更新數值。
- 3D 仍由用戶手動切換，桌面與手機 GLB 載入、復原與可操作狀態不得退步。
- **僅 CI 全綠才合併。**

## ACFH 2.0 未完成的後續階段

- 真正高品質、**合法授權且經驗證分件**的 AKM PBR 3D 資產：各槍管、槍口、護木、機匣、槍托、握把、彈匣與掛點。現有只有少量網格，不能透過追加 Shader 變成全分件。
- 分件模型與當前裝備 state 聯動、鏡頭轉至部位、實際部件切換和依附槽約束。
- 區分 GPU/網路性能級別的渲染策略（如 LOD、KTX2/Draco、動態解析度）；需要不同 Android 設備現場測試。
- 真實接觸陰影、環境貼圖、後處理及材質性能預算，在有可信 3D 資產後再設計。
- 本階段的 CSS 光照是美術手段，不是與射擊遊戲畫面同等的 3D 物理渲染。
